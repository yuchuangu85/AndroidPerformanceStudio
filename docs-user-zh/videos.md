# 视频文档

## 教程视频

这些视频介绍了如何使用 Firefox Profiler，以及分析器工作原理背后的部分理论。它们是快速上手工具工作流程的好方法。

| 视频                                             | 描述                                                                                                                                                                                            |
| ------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Firefox Profiler 简介][intro]                   | 本介绍视频说明了如何设置并开始分析。它简要解释了架构的工作原理，以便更好地理解各种工具和数据来源之间的关系。   |
| [样本和标记][samples]                    | 分析器主要收集两种不同类型的数据。从样本和标记的角度来思考配置文件是理解底层数据的有效方式。         |
| [调用树（第 1 部分）- 基础][calltree1]      | 调用树是理解配置文件最有用的报告之一。本视频通过一些非常简化的示例，逐步讲解调用树的构建方式及其含义。 |
| [调用树（第 2 部分）- 真实录制][calltree2] | 将调用栈和调用树的理论应用于 profiler.firefox.com 的界面。                                                                                                                  |
| [调用树（第 3 部分）- 分支][calltree3]       | 真实代码存在分支，本演示逐步讲解分支如何影响调用树，并通过简化的代码示例展示如何理解它们。                                      |
| [多线程和异步代码][threads]        | 逐步了解和分析多进程配置文件。                                                                                                                        |

## Profiling 的乐趣

这些半周更的剧集使用 Firefox Profiler 检查 Firefox 性能配置文件。它们是长篇内容，有助于深入了解如何在真实世界的配置文件上进行分析。请注意，过去该项目被称为 "perf.html"，许多视频仍沿用此名称。

- [查看所有剧集][joy]
