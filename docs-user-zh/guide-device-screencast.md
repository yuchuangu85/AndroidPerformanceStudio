# 设备投屏

设备投屏模块在应用内实时镜像已连接 Android 设备的屏幕，并允许使用鼠标和键盘反向控制设备。适用于检查界面行为、在性能分析旁复现交互、或在真机上验证帧问题。

## 开始投屏

1. 用 USB 连接已开启 USB 调试并授权本机的设备。
2. 从首页卡片或导航栏打开**设备投屏**。
3. 在下拉框中选择设备（点击**刷新**重新扫描），点击**开始投屏**。

应用会向设备 `/data/local/tmp` 推送一个约 100 KB 的 scrcpy server，建立 adb 反向隧道后开始镜像。设备上不安装任何应用，也不需要 root。停止会话或关闭模块会自动移除隧道与推送的文件。

## 控制方式

- **鼠标**：点击即触摸，拖动即滑动，滚轮即滚动。坐标按镜像画布区域换算（留白区域不注入）。
- **导航键**：底部栏的 返回 / 主页 / 最近任务 按钮注入对应的 Android 按键。
- **文本**：在底部输入框输入文本，点击**发送到设备**，写入设备剪贴板并粘贴到焦点输入框。

## 会话状态

| 状态 | 含义 |
|---|---|
| 空闲 | 无会话；选择设备后开始。 |
| 连接中 | 推送/隧道/握手中；不可中断。 |
| 投屏中 | 镜像运行；画布显示实时画面。 |
| 已断开 | 设备或流中断；重新开始即可重连。 |
| 失败 | 启动失败；错误信息说明原因（如设备未授权）。 |

## 常见问题

- **设备列表为空**：先运行 `adb devices` 确认设备状态为 `device`（而非 `unauthorized`/`offline`），再点击刷新。
- **启动报 server 错误**：可能有其他 scrcpy 实例占用设备；停止后重试。
- **高分辨率设备帧率低**：镜像使用软件 H.264 解码，CPU 占用与分辨率相关；这是内嵌解码器的已知取舍。
