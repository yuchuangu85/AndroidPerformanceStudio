# Archive analysis references without source or credentials

Exported reports preserve analysis sessions, findings, evidence summaries, immutable repository identities, relative source locations, content hashes, and model/prompt/policy provenance. They exclude credentials, absolute local paths, raw source snippets, complete indexes, caches, and unredacted request bodies. On another machine remote sources are re-fetched by revision, local workspaces require explicit rebinding, and hash mismatches force re-resolution instead of silent navigation.
