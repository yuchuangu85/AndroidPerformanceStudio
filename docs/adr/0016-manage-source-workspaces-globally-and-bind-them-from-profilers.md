# Manage source workspaces globally and bind them from profilers

The desktop application provides a global Source Workspaces surface for Local, GitHub, and AOSP providers, snapshot/index/cache status, credentials, and build-evidence associations. Layout Inspector and Simpleperf bind reports to existing workspaces and expose a contextual attach shortcut rather than implementing separate import flows. Workspace removal reports historical analysis-session references before invalidating cached navigation.
