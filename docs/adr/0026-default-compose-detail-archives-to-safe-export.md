# Default Compose inspection detail archives to safe export

Compose inspection details export as a Safe Inspection Archive by default: runtime strings and parameter values are replaced according to a versioned policy while structural, type, source, truncation, and omission evidence remains. Full-fidelity export is a separate explicit confirmation for sensitive local workflows, and neither mode includes credentials, session tokens, private device paths, inspector executables, or source bodies; imported raw values also remain excluded from AI requests unless separately authorized.
